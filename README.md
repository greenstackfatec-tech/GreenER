# GreenER-Fatec
Greener é uma plataforma de GreenOps e monitoramento em tempo real que estima o consumo energético e as emissões de carbono equivalente (CO²e) de aplicações de software, transformando métricas de infraestrutura (CPU, RAM, disco e rede) e dados regionais da matriz elétrica em indicadores práticos de impacto ambiental.
